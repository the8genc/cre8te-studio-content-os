# Newsletter Editor Skill

## Purpose
Assemble that week's published and scheduled content packages into a single
warm, curated weekly digest email. Run Thursday evening for Friday send.

## When to Use
Run every Thursday at 8pm if no Newsletter Draft exists for the current week.

## Hero Story Selection Criteria (ranked)
1. Summit Recording source > Mini Pod > Testimonial > ITL
2. First-time topic > repeated theme
3. High specificity angle > broad insight
4. Community moment > individual achievement

## Newsletter Structure (exact — do not deviate)

```
SUBJECT: [curiosity hook + community signal, ≤60 chars]
PREVIEW: [completes the subject's thought, ≤90 chars]

---

[HERO SECTION]
1 headline + 2-3 sentences of context + the core insight
Link to full content

---

THIS WEEK IN CRE8TE
[3-5 items, each: 1-sentence blurb + link]

---

COMMUNITY SPOTLIGHT
[1 testimonial or ITL moment — quote format if possible]

---

WHAT'S COMING
[1-2 sentences teasing next week's known content]

---

[CTA]
[Single clear action: join, attend, or share]
```

## Subject Line Formula
- Option A: [Specific insight] + [community relevance signal]
  → "The mindset shift that changed how 400 founders think about community"
- Option B: [Surprising specific claim]
  → "We recorded something at the Summit you need to hear"
- Option C: [What's inside + why it matters]
  → "This week's most-shared moment from the Cre8te community"

## Tone Rules
- Write as if one trusted community member is emailing another
- Warmth first, information second
- Never "content" or "assets" — say "what we captured", "this week's conversations"
- Reference real speakers and moments — never generic summaries
